# Credits

Fan remake inspired by *Ironman Ivan Stewart's Super Off Road* (Leland, 1989).
No original graphics, sounds or code are used. Track layouts are new designs
using the original track names.

## Original assets made for this project
- Trucks: low-poly model rendered with Blender (`tools/blender/render_trucks.py`) and converted to pixel art.
- Tracks, crowd, flagman, pickups, icons: generated procedurally / drawn as pixel maps (`scripts/track/track.gd`, `tools/gen_pixel_art.py`).
